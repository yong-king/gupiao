# Analysis Report Page Spec

## 1. Background

Frontend needs report data adapters before full Vue pages are built.

## 2. Goals

- Provide display model for report cards.
- Show data time and source.

## 3. Non-Goals

- Do not build final Vue page here.

## 4. Functional Scope

### Must Have

- Frontend report formatter.
- Tests for empty and populated reports.

## 5. Testing

- Node tests pass.

## 6. Acceptance Criteria

- Given report data When formatted Then risk and data time are visible.

## 7. Definition Of Done

- Frontend tests pass.
