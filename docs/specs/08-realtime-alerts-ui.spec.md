# Realtime Alerts UI Spec

## 1. Background

The MVP should display alert messages from the notification center.

## 2. Goals

- Format alert messages.
- Highlight risk level and data time.

## 3. Non-Goals

- Do not implement WebSocket in this plan.

## 4. Functional Scope

### Must Have

- Alert message formatter.

## 5. Testing

- Formatter tests.

## 6. Acceptance Criteria

- Given alert message data When formatted Then signal, risk level, and data time are present.

## 7. Definition Of Done

- Tests pass.
