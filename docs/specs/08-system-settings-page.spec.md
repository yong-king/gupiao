# System Settings Page Spec

## 1. Background

Users need safe refresh-mode settings and notification preferences.

## 2. Goals

- Display refresh mode choices.
- Do not expose automatic trading options.

## 3. Non-Goals

- Do not implement external notification setup here.

## 4. Functional Scope

### Must Have

- Settings model.
- Safe mode labels.

## 5. Testing

- Settings options do not include trading actions.

## 6. Acceptance Criteria

- Given settings are rendered Then manual, conservative, and standard modes are available.

## 7. Definition Of Done

- Tests pass.
