# Regression Test Spec

## 1. Background

The final plan must verify all completed modules.

## 2. Goals

- Run Go tests.
- Run Python tests.
- Run frontend tests.
- Run frontend syntax checks.

## 3. Non-Goals

- Do not require live broker or market data.

## 4. Functional Scope

### Must Have

- Regression command list.
- Release checklist.

## 5. Testing

- All local test commands pass.

## 6. Acceptance Criteria

- Given the MVP is complete When regression runs Then all local tests pass.

## 7. Definition Of Done

- Regression results recorded.
