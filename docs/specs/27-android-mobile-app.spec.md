# 27 安卓移动端应用规范

## 1. 背景

当前项目已经具备后端 API、Python Agent、前端操作台、股票助手、多智能体研究工作流和本地部署能力，但主要使用方式仍然是桌面浏览器。对于高频查看持仓、提醒、行情和股票助手的场景，用户还需要一个可安装在安卓手机上的移动应用。

现阶段项目已经有：

- Go 后端 API；
- Python Agent；
- 静态前端控制台；
- 登录鉴权、股票池、持仓、提醒、日志、工作流、股票助手。

因此安卓 App 的第一阶段目标不应是完全重做一套后端或另起一套产品，而应在复用现有接口、鉴权和业务能力的前提下，提供一个真正可安装、可登录、可查看核心信息、可进行核心操作的安卓应用。

## 2. 目标

- 提供一个面向安卓手机的可安装 App。
- 复用现有后端 API、认证机制和股票助手能力。
- 提供适合手机竖屏操作的核心页面和导航结构。
- 支持用户在移动端完成高频核心操作：
  - 登录；
  - 查看持仓、自选和提醒；
  - 查看单只股票详情；
  - 使用股票助手；
  - 查看多智能体工作流和最近研究记录。
- 为后续原生通知、推送、深链和生物识别登录预留架构空间。

## 3. 非目标

- 第一阶段不要求实现完整桌面控制台的所有页面和所有配置能力。
- 第一阶段不要求实现 iOS。
- 第一阶段不要求离线行情、复杂图表编辑器或完整本地数据库同步。
- 第一阶段不要求接入真实安卓推送服务，但要预留接口和数据模型。
- 不实现自动交易。

## 4. 技术路线

### 4.1 第一阶段选型

第一阶段移动端采用“复用现有前端逻辑 + 新建移动端壳与移动端页面”的方案：

- 新增 `mobile/` 目录；
- 使用 `Capacitor + Android` 作为安卓打包与设备壳；
- 移动端 UI 使用项目现有前端技术栈延续实现；
- API 继续调用现有 `backend`；
- 股票助手继续调用现有后端 `/api/assistant/chat` 和 `/api/assistant/chat/stream`。

这样做的原因：

- 当前项目已有可运行的前端和 API；
- 安卓第一阶段目标是尽快提供可安装、可验证、可演进的版本；
- 相比直接切到 Flutter 或完整原生 Kotlin，Capacitor 路线能最大化复用现有页面、状态和接口逻辑；
- 后续如果移动端业务独立性变强，再考虑逐步演进为更强的跨端方案。

### 4.2 目录约定

新增目录结构建议：

```text
mobile/
  package.json
  capacitor.config.*
  android/
  src/
  README.md
```

## 5. 用户与使用场景

### 5.1 用户场景

- 用户通勤时打开 App，快速查看持仓、提醒和重点股票。
- 用户收到提醒后，进入某只股票详情页查看最新行情、日历、K 线和历史研究摘要。
- 用户在手机上直接问股票助手：“这只股票当前最需要关注什么？”
- 用户查看最近一次高关注工作流是否成功执行，研究摘要是否已更新。

### 5.2 核心使用频次

- 高频：持仓、提醒、股票详情、股票助手。
- 中频：自选列表、工作流记录、系统状态。
- 低频：账户配置、复杂系统设置、操作日志全文检索。

## 6. 功能范围

### 6.1 第一阶段必须实现

#### 6.1.1 应用壳与运行能力

- 可通过 Android Studio 构建 APK 或 debug 安装包。
- App 启动后进入移动端首页，而不是桌面控制台布局。
- 支持配置 API Base URL。
- 支持开发环境连接本地局域网后端。

#### 6.1.2 登录与会话

- 登录页；
- 注册后登录或直接登录；
- 本地安全保存 token；
- 会话过期后自动跳转登录页；
- 退出登录。

#### 6.1.3 移动端导航

底部导航栏至少包含：

- 首页
- 持仓
- 自选
- 提醒
- 助手

二级页面至少包含：

- 股票详情页
- 工作流记录页
- 设置页

#### 6.1.4 首页

首页需展示：

- 账户/用户简要信息；
- 今日重点提醒摘要；
- 持仓概览；
- 自选概览；
- 最近研究工作流摘要；
- 最近关注股票快捷入口。

#### 6.1.5 持仓页

- 展示持仓列表；
- 展示数量、成本、关注等级、最新价、浮动盈亏；
- 点击进入股票详情页；
- 支持手动刷新持仓行情。

#### 6.1.6 自选页

- 展示股票池或自选股票列表；
- 支持切换当前股票池；
- 支持查看股票的最新价格和状态；
- 点击进入股票详情页。

#### 6.1.7 提醒页

- 展示提醒事件和通知记录；
- 可按风险等级突出显示；
- 支持标记已读。

#### 6.1.8 股票详情页

- 展示股票基本信息；
- 展示实时行情卡片；
- 展示 K 线或价格趋势图；
- 展示涨跌日历或最近涨跌摘要；
- 展示公司与产品分析；
- 展示最近研究摘要；
- 支持触发“采集并分析当前股票”；
- 支持触发关注等级工作流。

#### 6.1.9 股票助手页

- 提供移动端聊天体验；
- 支持选择股票；
- 支持多轮会话；
- 展示模型、提供方、调用状态；
- 支持流式输出；
- 支持查看上下文摘要。

#### 6.1.10 设置页

- 配置 API 地址；
- 查看当前用户、模型状态、后端依赖状态；
- 主题模式可选；
- 查看 App 版本与环境信息。

### 6.2 第一阶段应该实现

- 支持下拉刷新；
- 支持移动端骨架屏或加载态；
- 支持移动端错误态和空状态；
- 支持深色模式默认体验；
- 支持局域网直连说明；
- 支持后续推送开关设置的占位能力。

### 6.3 第一阶段范围外

- 原生消息推送正式接入；
- 生物识别登录；
- 离线缓存数据库；
- iOS 构建；
- 平板专属布局；
- 完整日志检索、复杂系统管理页。

## 7. 界面与交互要求

### 7.1 设计原则

- 以竖屏为主；
- 优先单列纵向布局；
- 适合单手操作；
- 重点信息优先可扫读；
- 不沿用桌面侧边栏；
- 不出现多个小面板横向挤压。

### 7.2 移动端导航结构

```text
启动页
-> 登录
-> 首页
  -> 持仓
    -> 股票详情
  -> 自选
    -> 股票详情
  -> 提醒
  -> 助手
  -> 设置
```

### 7.3 移动端组件要求

- 列表项高度稳定；
- 关键操作按钮尺寸适合触摸；
- 图表区域宽度占满；
- 聊天输入框固定在底部；
- 底部导航始终可用；
- 长表格在移动端转换为卡片或纵向信息块。

## 8. 后端与接口要求

安卓 App 第一阶段不新增独立移动端后端服务，复用现有 API。

### 8.1 直接复用接口

- `/api/auth/register`
- `/api/auth/login`
- `/api/holdings`
- `/api/watchlists`
- `/api/alerts`
- `/api/notifications`
- `/api/market/collect`
- `/api/market/snapshots`
- `/api/market/daily-changes`
- `/api/market/klines`
- `/api/stocks/profile`
- `/api/workflows`
- `/api/workflows/research/run`
- `/api/assistant/chat`
- `/api/assistant/chat/stream`
- `/api/system/dependencies`

### 8.2 需要补充的接口契约要求

- 现有接口 Swagger/OpenAPI 需要持续覆盖移动端使用到的关键接口；
- 移动端依赖的响应字段必须稳定；
- 对于适合手机端的摘要页，后续可新增移动端聚合接口，但第一阶段不是必须。

## 9. 安全要求

- Token 不得明文写入日志；
- App 内不得暴露交易能力；
- App 内不得保存交易密码；
- API 地址配置需要有显式说明；
- 如果连接的是 HTTP 本地开发环境，需要在开发文档中说明仅限测试使用。

## 10. 配置与部署要求

### 10.1 本地开发

- 支持 Android 模拟器；
- 支持真机调试；
- 支持通过局域网访问本地 Docker 启动的后端服务；
- 文档必须说明：
  - 手机如何连接后端；
  - `API_BASE` 如何配置；
  - 安卓调试构建怎么运行。

### 10.2 构建

- 提供移动端构建命令；
- 提供 `mobile/README.md`；
- 提供最小可运行 Android 工程文件；
- 需要能够产出 debug APK。

## 11. 测试要求

### 11.1 必须测试

- 移动端基础页面渲染；
- 登录流程；
- 会话过期处理；
- 持仓列表与详情页；
- 股票助手消息发送与流式响应；
- API 地址配置；
- 安卓壳可成功构建。

### 11.2 建议测试

- 小屏手机下的布局稳定性；
- 弱网下加载与错误态；
- 不同安卓版本兼容性；
- WebView 中 SSE 流式响应行为。

## 12. 验收标准

- 仓库中存在 `mobile/` 目录与安卓构建配置。
- 安卓 App 可安装并连接现有后端。
- 用户可在安卓端完成登录、查看持仓/提醒/详情、使用股票助手。
- 页面布局适合手机竖屏操作。
- 文档包含本地安卓开发与构建说明。
- 不出现自动交易能力。
